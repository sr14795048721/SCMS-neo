# SCMS+ Delivery Roadmap

## Milestone 1 (Week 1-4)

- Gateway + Core online.
- Login/JWT, club/activity/registration closed loop.
- Docker Compose for postgres/redis/core/gateway.

## Milestone 2 (Week 5-8)

- File service + MinIO.
- Kafka-based async notification/audit.
- Feign-based service integration starts when service split happens.

## Milestone 3 (Week 9-12)

- Metrics dashboard enhancement.
- Helm chart and K8s manifests.
- Perf tests and recovery runbooks.
